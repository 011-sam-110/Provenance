# Accounts, sign-in and settings sync: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Optional email-and-password accounts on Supabase that sync a person's console settings across devices, with self-serve deletion and a first-party count of returning accounts.

**Architecture:** The browser talks to Supabase directly with `@supabase/supabase-js` and row-level security. localStorage stays the source of truth for the running console: a hook in `savePersisted` queues uploads of allowlisted keys, and a boot step writes newer account values into localStorage and reloads once. The Lightsail box gets one route, `POST /api/account/delete`.

**Tech Stack:** Next.js 15.5 (App Router, standalone on Lightsail), React 19, TypeScript 5.7, vitest 2 (node environment), `@supabase/supabase-js` ^2.117.3 (locked at 2.117.3), Supabase Postgres 15+, Brevo SMTP.

**Spec:** `docs/superpowers/specs/2026-10-15-accounts-design.md`. Read it first.

**Execution (Sam, 2026-10-15):** subagent-driven. One fresh agent per task, a review between tasks, one PR per milestone. M0 is done by the coordinating session in Sam's Chrome, with Sam approving each step.

## Global Constraints

- Every account feature is DORMANT when `NEXT_PUBLIC_SUPABASE_URL` or `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` is unset: no UI, no network call, no Supabase script loaded.
- `SUPABASE_SECRET_KEY` is read only in `lib/account/serverAuth.ts` (from M4). Never in `components/`, never in a `"use client"` module, never in CI. Every gated route calls `requireUser()` from that file.
- Read env vars as literal `process.env.NAME` expressions. Next.js inlines only literal `NEXT_PUBLIC_*` reads, and `tests/unit/sources-status.test.ts` finds gates by the literal text.
- The session is stored in localStorage under `tn.account.session`. No cookie.
- Secrets never leave the device: `tn.telegram.v1` is not synced; `webhookUrl`, `fired`, `seeded` (alerting), `discordWebhook` (notifications) and `activeId` (pins) are stripped before upload.
- Never show a raw Supabase or upstream error string to a visitor. Map every error to a fixed sentence in `lib/account/errors.ts`.
- All UI strings and error text: ASD-STE100 Strict (active voice, one idea per sentence, at most 20 words per instruction). User-facing copy uses hyphens, never em or en dashes.
- Tests are vitest, node environment, `tests/unit/**/*.test.ts`. No React testing library exists. UI is verified by tsc, by hand against the dev project, and by `tests/e2e/accounts.spec.ts` (not in the gate).
- Gate: `npx tsc --noEmit && npm test`. Full check: `npm run build`.
- One commit per milestone, message `M<n>: <name>`, **solo attribution, no co-author trailer** (repo CLAUDE.md). Each milestone is a fresh branch off the latest `origin/main` and its own PR. Stage explicit paths only; never `git add -A`.
- Every PR that adds a test file updates `lib/marketing/repo-facts.data.ts` (`files` and `cases`, from `npx vitest list`), or `tests/unit/landing-repo-facts.test.ts` fails.

```ts
// THE ACCOUNTS SWITCH. Accounts exist on a deployment only when both public Supabase
// values were present at BUILD time. Next.js inlines a NEXT_PUBLIC_* read into the client
// bundle only when it is written as a literal `process.env.NAME`, which is why the two
// reads below are literals and not a lookup. tests/unit/sources-status.test.ts finds
// credential gates by that same literal text, and KEY_REQUIREMENTS declares both.
//
// Unset, every account feature is dormant: no UI, no network call, no library download.
// That is how self-hosters and preview builds see the site.

/** Where supabase-js keeps the session. localStorage, never a cookie. */
export const SESSION_STORAGE_KEY = "tn.account.session";

export interface AccountsConfig {
  url: string;
  publishableKey: string;
}

/** PURE: both values present and non-blank, or null. */
export function accountsConfigFrom(
  url: string | undefined,
  key: string | undefined,
): AccountsConfig | null {
  const u = url?.trim();
  const k = key?.trim();
  if (!u || !k) return null;
  return { url: u, publishableKey: k };
}

export function accountsConfig(): AccountsConfig | null {
  return accountsConfigFrom(
    process.env.NEXT_PUBLIC_SUPABASE_URL,
    process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY,
  );
}

export function accountsConfigured(): boolean {
  return accountsConfig() !== null;
}

/** Is there a stored session? A cheap localStorage read that loads no library. */
export function hasStoredSession(storage?: Pick<Storage, "getItem">): boolean {
  try {
    const s = storage ?? (typeof window === "undefined" ? null : window.localStorage);
    return !!s?.getItem(SESSION_STORAGE_KEY);
  } catch {
    return false;
  }
}
```

```ts
// WHAT SYNCS. The one list of localStorage keys that may leave this device when someone is
// signed in, and the rules for each. The database holds the same list as a check
// constraint (supabase/migrations/20261015000000_accounts.sql), and
// tests/unit/account-sync-keys.test.ts fails if the two disagree.
//
// THE RULE. A key syncs if it holds something the person made or chose. A key stays on the
// device if it holds a secret, a setting for this one screen, a cache, a "seen it" flag or
// analytics state. tn.telegram.v1 is a bot token, so it is not here at all. Three keys
// carry a secret or a per-device field inside an otherwise shareable object; `localOnly`
// names those fields with the value a fresh device gets, and the transforms in this file
// strip them before upload and put the local value back after download.
//
// Adding a key here also needs: the same key in a NEW migration's check constraint, and a
// line on /privacy. Removing one: a migration that deletes its rows.

export interface ListRule {
  /** Where the array of `{ id }` items lives: the stored value itself, or its `pins` field. */
  at: "root" | "pins";
  /** The store's own cap, applied after a merge. */
  cap?: number;
  /** Which end survives the cap. Newest-first stores keep "first". */
  keep?: "first" | "last";
}

export interface SyncKeySpec {
  key: string;
  /** Present for list stores: on first sign-in, merge by `id` instead of replacing. */
  list?: ListRule;
  /** Top-level fields that never leave this device, with the value a fresh device gets. */
  localOnly?: Readonly<Record<string, unknown>>;
}

export const SYNC_KEYS: readonly SyncKeySpec[] = [
  { key: "tn.watchlist.v1", list: { at: "root", cap: 40, keep: "first" } },
  { key: "tn.map.pins.v1", list: { at: "pins" }, localOnly: { activeId: null } },
  { key: "tn.events.assets.v1", list: { at: "root", cap: 50, keep: "first" } },
  { key: "tn.mkalerts.v1", list: { at: "root", cap: 60, keep: "last" } },
  { key: "tn.console.v1" },
  { key: "tn.console.boards.v1" },
  { key: "tn.console.presets.v1" },
  { key: "tn.console.activePreset.v1" },
  { key: "tn.console.sceneChrome.v1" },
  { key: "tn.inspector.v1" },
  { key: "tn.variant.v1" },
  { key: "tn.scope.v1" },
  { key: "tn.events.alerting.v1", localOnly: { webhookUrl: "", fired: [], seeded: false } },
  { key: "tn.notify.rules.v1" },
  { key: "tn.notifications.v1", localOnly: { discordWebhook: "" } },
  { key: "tn.keymap.v1" },
  { key: "tn.lang.v1" },
  { key: "tn.hud.v1" },
  { key: "tn.camslot.prefs.v1" },
];

export const SYNC_KEY_NAMES: readonly string[] = SYNC_KEYS.map((s) => s.key);

const BY_KEY = new Map(SYNC_KEYS.map((s) => [s.key, s]));

export function syncSpec(key: string): SyncKeySpec | undefined {
  return BY_KEY.get(key);
}
```

```sql
-- supabase/migrations/20261015000000_accounts.sql
-- Accounts for Provenance. Design: docs/superpowers/specs/2026-10-15-accounts-design.md
-- Row-level security is ON for every table. Policies use (select auth.uid()) so Postgres
-- evaluates it once per statement, not once per row.

-- ── profiles ─────────────────────────────────────────────────────────────────
create table public.profiles (
  user_id    uuid primary key references auth.users (id) on delete cascade,
  username   text not null unique
             check (char_length(username) between 3 and 24 and username ~ '^[a-z0-9_]+$'),
  created_at timestamptz not null default now()
);

alter table public.profiles enable row level security;

create policy "profiles: read own" on public.profiles
  for select to authenticated using (user_id = (select auth.uid()));

create policy "profiles: update own" on public.profiles
  for update to authenticated
  using (user_id = (select auth.uid()))
  with check (user_id = (select auth.uid()));

-- Only `username` can change. There is no insert policy: the trigger below inserts.
revoke insert, update, delete on public.profiles from anon, authenticated;
grant update (username) on public.profiles to authenticated;

create function public.handle_new_user() returns trigger
  language plpgsql security definer set search_path = '' as $$
begin
  insert into public.profiles (user_id, username)
  values (new.id, lower(new.raw_user_meta_data ->> 'username'));
  return new;
end;
$$;

-- A missing or taken username fails this insert, so the sign-up fails and no account
-- without a profile can exist.
create trigger on_auth_user_created
  after insert on auth.users
  for each row execute function public.handle_new_user();

create function public.username_available(name text) returns boolean
  language sql stable security definer set search_path = '' as $$
  select not exists (select 1 from public.profiles where username = lower(name));
$$;

revoke all on function public.username_available(text) from public;
grant execute on function public.username_available(text) to anon, authenticated;

  user_id    uuid not null references auth.users (id) on delete cascade,

               'tn.keymap.v1',
               'tn.lang.v1',
               'tn.hud.v1',
               'tn.camslot.prefs.v1'
             )),
  version    int not null check (version >= 1),
  value      jsonb not null check (pg_column_size(value) <= 65536),
  updated_at timestamptz not null default now(),
  primary key (user_id, key)
);

alter table public.user_state enable row level security;

create policy "user_state: own rows" on public.user_state
  for all to authenticated
  using (user_id = (select auth.uid()))
  with check (user_id = (select auth.uid()));

revoke all on public.user_state from anon;

-- The server sets the time, and an old client cannot overwrite a newer schema version.
create function public.user_state_guard() returns trigger
  language plpgsql set search_path = '' as $$
begin
  if tg_op = 'UPDATE' and new.version < old.version then
    raise exception 'version downgrade refused' using errcode = 'check_violation';
  end if;
  new.updated_at := now();
  return new;
end;
$$;

  before insert or update on public.user_state

  for insert to authenticated
  with check (user_id = (select auth.uid()) and day = (now() at time zone 'utc')::date);

revoke update, delete on public.activity_days from anon, authenticated;
revoke all on public.activity_days from anon;

-- Both projects were created with "Automatically expose new tables" OFF (Supabase's own
-- recommendation, 2026-10-15), so a new table has NO privileges for the API roles until it
-- is granted here. Row-level security then narrows each grant to the caller's own rows.
-- anon gets nothing on any table; it can only call username_available().
grant usage on schema public to anon, authenticated;
grant select on public.profiles to authenticated;
grant update (username) on public.profiles to authenticated;
grant select, insert, update, delete on public.user_state to authenticated;
grant select, insert on public.activity_days to authenticated;
-- service_role (the secret key, server and scripts only) bypasses row-level security but
-- still needs table privileges. It gets READ only: scripts/check-account-rls.mjs reads the
-- tables to check the result of each forbidden write.
-- Deleting a user goes through the Auth admin API, and the foreign-key cascade runs as the
-- table owner, so no delete grant is needed.

grant select on public.profiles, public.user_state, public.activity_days to service_role;
```

```js
// Proves the row-level security in supabase/migrations/20261015000000_accounts.sql against
// a REAL project. It makes two throwaway users, tries every forbidden thing, and deletes
// both users at the end. Run it against the DEV project only:

import { createClient } from "@supabase/supabase-js";
import { randomBytes } from "node:crypto";

const url = process.env.NEXT_PUBLIC_SUPABASE_URL;
const pub = process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY;
const secret = process.env.SUPABASE_SECRET_KEY;

  console.error("Refusing: set ACCOUNTS_RLS_TARGET=dev. This script creates and deletes users.");
  process.exit(2);
}
if (!url || !pub || !secret) {
  console.error("Missing NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY or SUPABASE_SECRET_KEY.");
  process.exit(2);
}

const opts = { auth: { persistSession: false, autoRefreshToken: false } };
const admin = createClient(url, secret, opts);
const anon = createClient(url, pub, opts);
let failed = 0;
const check = (name, ok, detail = "") => {
  console.log(`${ok ? "PASS" : "FAIL"}  ${name}${ok ? "" : `  ${detail}`}`);
  if (!ok) failed++;
};

const tag = randomBytes(4).toString("hex");
const password = `rls-${randomBytes(12).toString("hex")}`;
async function makeUser(name) {
  const email = `rls-${name}-${tag}@example.com`;
  const { data, error } = await admin.auth.admin.createUser({
    email, password, email_confirm: true, user_metadata: { username: `rls_${name}_${tag}` },
  });
  if (error) throw new Error(`createUser ${name}: ${error.message}`);
  const client = createClient(url, pub, opts);
  const { error: e2 } = await client.auth.signInWithPassword({ email, password });
  if (e2) throw new Error(`signIn ${name}: ${e2.message}`);
  return { id: data.user.id, client, username: `rls_${name}_${tag}` };
}

const today = new Date().toISOString().slice(0, 10);
const yesterday = new Date(Date.now() - 86_400_000).toISOString().slice(0, 10);
let A, B;
try {
  A = await makeUser("a");
  B = await makeUser("b");

  const { data: profA } = await A.client.from("profiles").select("username").eq("user_id", A.id).single();
  check("trigger made A's profile", profA?.username === A.username, JSON.stringify(profA));

  const ins = await A.client.from("user_state").upsert({ user_id: A.id, key: "tn.watchlist.v1", version: 1, value: [{ id: "x" }] });
  check("A writes an allowlisted key", !ins.error, ins.error?.message);

  const peek = await B.client.from("user_state").select("key").eq("user_id", A.id);
  check("B reads none of A's rows", !peek.error && peek.data.length === 0, JSON.stringify(peek));

  const forge = await B.client.from("user_state").upsert({ user_id: A.id, key: "tn.lang.v1", version: 1, value: "en" });
  check("B cannot write a row for A", !!forge.error);

  const evil = await A.client.from("user_state").upsert({ user_id: A.id, key: "tn.evil.v1", version: 1, value: {} });
  check("a key outside the allowlist is refused", !!evil.error);

  const big = await A.client.from("user_state").upsert({ user_id: A.id, key: "tn.hud.v1", version: 1, value: { s: "x".repeat(70_000) } });
  check("a value over 64 KB is refused", !!big.error);

  await A.client.from("user_state").upsert({ user_id: A.id, key: "tn.keymap.v1", version: 2, value: {} });
  const down = await A.client.from("user_state").upsert({ user_id: A.id, key: "tn.keymap.v1", version: 1, value: {} });
  check("a version downgrade is refused", !!down.error);

  const day = await A.client.from("activity_days").insert({ user_id: A.id, day: today });
  check("A records today", !day.error, day.error?.message);
  const back = await A.client.from("activity_days").insert({ user_id: A.id, day: yesterday });
  check("A cannot back-date a day", !!back.error);

  for (const t of ["profiles", "user_state", "activity_days"]) {
    const r = await anon.from(t).select("*").limit(1);
    check(`anonymous reads nothing from ${t}`, !!r.error || r.data.length === 0, JSON.stringify(r.data));
  }

  const taken = await anon.rpc("username_available", { name: A.username.toUpperCase() });
  check("username_available sees a taken name, ignoring case", taken.data === false, JSON.stringify(taken));
  const free = await anon.rpc("username_available", { name: `free_${tag}` });
  check("username_available sees a free name", free.data === true, JSON.stringify(free));

  await B.client.from("profiles").update({ username: `hijack_${tag}` }).eq("user_id", A.id);
  const { data: still } = await admin.from("profiles").select("username").eq("user_id", A.id).single();
  check("B cannot rename A", still?.username === A.username, JSON.stringify(still));

  const bad = await A.client.from("profiles").update({ username: "Bad Name!" }).eq("user_id", A.id);
  check("an invalid username is refused", !!bad.error);
  const ok = await A.client.from("profiles").update({ username: `renamed_${tag}` }).eq("user_id", A.id);
  check("A renames self", !ok.error, ok.error?.message);

  await admin.auth.admin.deleteUser(A.id);
  const left = await admin.from("user_state").select("key").eq("user_id", A.id);
  const leftDays = await admin.from("activity_days").select("day").eq("user_id", A.id);
  check("deleting A cascades every row", left.data?.length === 0 && leftDays.data?.length === 0);
  A = null;
} catch (e) {
  check("script ran to the end", false, String(e));
} finally {
  for (const u of [A, B]) if (u) await admin.auth.admin.deleteUser(u.id);
}
console.log(failed ? `\n${failed} check(s) FAILED` : "\nAll checks passed");
process.exit(failed ? 1 : 0);
```

```ts
// lib/account/username.ts
// The username is a display name. Nobody signs in with it. The database enforces the same
// rule (supabase/migrations/20261015000000_accounts.sql); this copy exists so the form can
// say what is wrong before a round trip.

export function normalizeUsername(raw: string): string {
  return raw.trim().toLowerCase();
}

/** PURE: one sentence naming the problem, or null when the name is valid. */
export function usernameProblem(raw: string): string | null {
  const name = normalizeUsername(raw);
  if (name.length < 3 || name.length > 24) return "Use 3 to 24 characters.";
  if (!/^[a-z0-9_]+$/.test(name)) return "Use only letters, numbers and _.";
  return null;
}
```

```ts
// lib/account/errors.ts
// EVERY account error a visitor can see is one of these sentences. An upstream message is
// never shown: it can change without notice, it can leak whether an address has an account,
// and it is not written for the people who read this console. Codes come from Supabase Auth
// (AuthError.code) and Postgres (23505 = unique violation on profiles.username).

export const GENERIC_ERROR = "Something went wrong. Try again in a minute.";

const BY_CODE: Record<string, string> = {
  invalid_credentials: "Email or password is wrong.",
  email_not_confirmed: "Confirm your email first. We sent you a link.",
  over_request_rate_limit: "Too many tries. Wait a minute and try again.",
  over_email_send_rate_limit: "Too many emails. Wait a few minutes and try again.",
  weak_password: "Use a longer password. 10 characters is the minimum.",
  same_password: "Use a password that is different from the old one.",
  otp_expired: "This link has expired. Ask for a new one.",
  email_address_invalid: "That email address does not look right.",
  "23505": "That username is taken.",
};

export function authErrorMessage(err: unknown): string {
  const code = err && typeof err === "object" && "code" in err ? String((err as { code: unknown }).code) : "";
  return BY_CODE[code] ?? GENERIC_ERROR;
}
```

```ts
"use client";
// ONE browser client, made on first use. The library is imported dynamically, so a visitor
// who never signs in and never opens the Account tab does not download it. Returns null
// when accounts are not configured, on the server, or when the import fails.

import type { SupabaseClient } from "@supabase/supabase-js";
import { accountsConfig, SESSION_STORAGE_KEY } from "@/lib/account/config";

let pending: Promise<SupabaseClient | null> | null = null;

export function getSupabase(): Promise<SupabaseClient | null> {
  if (pending) return pending;
  const cfg = accountsConfig();
  if (!cfg || typeof window === "undefined") return Promise.resolve(null);
  pending = import("@supabase/supabase-js")
    .then(({ createClient }) =>
      createClient(cfg.url, cfg.publishableKey, {
        auth: {
          storageKey: SESSION_STORAGE_KEY,
          persistSession: true,
          autoRefreshToken: true,
          // Email links carry a token_hash that /account/confirm verifies itself.
          detectSessionInUrl: false,
        },
      }),
    )
    .catch(() => {
      pending = null;
      return null;
    });
  return pending;
}
```

```ts
"use client";
// The account's UI state. Same shape as every lib/shell store: module state, a listener
// set, useSyncExternalStore. Not persisted: the session itself is supabase-js's job
// (tn.account.session), and the cached username lives in tn.account.sync.v1 (M3).

import { useSyncExternalStore } from "react";

export type AccountStatus = "off" | "loading" | "signed-out" | "signed-in";
export type SyncStatus = "idle" | "syncing" | "synced" | "offline";

export interface AccountState {
  status: AccountStatus;
  userId: string | null;
  email: string | null;
  username: string | null;
  sync: SyncStatus;
  lastSyncedAt: number | null;
  /** One sentence the Account tab shows, such as a pending reload. */
  notice: string | null;
}

const OFF: AccountState = {
  status: "off", userId: null, email: null, username: null, sync: "idle", lastSyncedAt: null, notice: null,
};

let state: AccountState = OFF;
const listeners = new Set<() => void>();

export const accountStore = {
  get(): AccountState {
    return state;
  },
  set(patch: Partial<AccountState>) {
    state = { ...state, ...patch };
    for (const l of listeners) l();
  },
  subscribe(listener: () => void): () => void {
    listeners.add(listener);
    return () => {
      listeners.delete(listener);
    };
  },
};

export function useAccount(): AccountState {
  return useSyncExternalStore(accountStore.subscribe, accountStore.get, () => OFF);
}
```

```ts
"use client";
// Every account action the UI can take. Each returns { ok } or { ok: false, error } with a
// fixed sentence from lib/account/errors.ts, never an upstream message.

import { getSupabase } from "@/lib/account/client";
import { accountStore } from "@/lib/account/store";
import { authErrorMessage, GENERIC_ERROR } from "@/lib/account/errors";
import { normalizeUsername, usernameProblem } from "@/lib/account/username";

export type AuthResult = { ok: true } | { ok: false; error: string };
const fail = (error: string): AuthResult => ({ ok: false, error });
const OK: AuthResult = { ok: true };

function confirmUrl(): string {
  return `${window.location.origin}/account/confirm`;
}

export async function signUp(input: { username: string; email: string; password: string }): Promise<AuthResult> {
  const problem = usernameProblem(input.username);
  if (problem) return fail(problem);
  const sb = await getSupabase();
  if (!sb) return fail(GENERIC_ERROR);
  const username = normalizeUsername(input.username);
  const free = await sb.rpc("username_available", { name: username });
  if (free.error) return fail(GENERIC_ERROR);
  if (free.data === false) return fail("That username is taken.");
  const { error } = await sb.auth.signUp({
    email: input.email.trim(),
    password: input.password,
    options: { data: { username }, emailRedirectTo: confirmUrl() },
  });
  // With "Confirm email" on, Supabase answers an existing address exactly like a new one.
  // The UI says "Check your email" in both cases, so nobody can probe which addresses exist.
  return error ? fail(authErrorMessage(error)) : OK;
}

export async function signIn(email: string, password: string): Promise<AuthResult> {
  const sb = await getSupabase();
  if (!sb) return fail(GENERIC_ERROR);
  const { error } = await sb.auth.signInWithPassword({ email: email.trim(), password });
  if (error) return fail(authErrorMessage(error));
  // A full reload runs the console's ordered hydrate sequence from the start. From M3 the
  // boot step (lib/account/runtime.ts) reconciles this browser with the account first.
  window.location.reload();
  return OK;
}

export async function signOut(): Promise<void> {
  const sb = await getSupabase();
  await sb?.auth.signOut({ scope: "local" });
  accountStore.set({ status: "signed-out", userId: null, email: null, username: null, sync: "idle", lastSyncedAt: null, notice: null });
}

export async function requestReset(email: string): Promise<AuthResult> {
  const sb = await getSupabase();
  if (!sb) return fail(GENERIC_ERROR);
  const { error } = await sb.auth.resetPasswordForEmail(email.trim(), { redirectTo: confirmUrl() });
  // Same answer whether or not the address has an account.
  if (error && (error as { code?: string }).code?.startsWith("over_")) return fail(authErrorMessage(error));
  return OK;
}

export async function verifyEmailLink(tokenHash: string, type: "email" | "signup" | "recovery"): Promise<AuthResult> {
  const sb = await getSupabase();
  if (!sb) return fail(GENERIC_ERROR);
  const { error } = await sb.auth.verifyOtp({ token_hash: tokenHash, type: type === "signup" ? "email" : type });
  return error ? fail(authErrorMessage(error)) : OK;
}

export async function setNewPassword(password: string): Promise<AuthResult> {
  const sb = await getSupabase();
  if (!sb) return fail(GENERIC_ERROR);
  const { error } = await sb.auth.updateUser({ password });
  return error ? fail(authErrorMessage(error)) : OK;
}

export async function renameUser(raw: string): Promise<AuthResult> {
  const problem = usernameProblem(raw);
  if (problem) return fail(problem);
  const sb = await getSupabase();
  const userId = accountStore.get().userId;
  if (!sb || !userId) return fail(GENERIC_ERROR);
  const username = normalizeUsername(raw);
  const { error } = await sb.from("profiles").update({ username }).eq("user_id", userId);
  if (error) return fail(authErrorMessage(error));
  accountStore.set({ username });
  return OK;
}
```

```ts
"use client";
// THE ACCOUNT'S BOOT STEP. ConsoleShell calls startAccount() once, in an effect that runs
// AFTER its hydrate effect. M2: find out who is signed in. M3 adds the sync pull here.

import { accountsConfigured, hasStoredSession } from "@/lib/account/config";

let started = false;

export async function startAccount(): Promise<void> {
  if (started) return;
  started = true;
  if (!accountsConfigured()) return accountStore.set({ status: "off" });
  if (!hasStoredSession()) return accountStore.set({ status: "signed-out" });

  accountStore.set({ status: "loading" });
  const sb = await getSupabase();
  const session = sb ? (await sb.auth.getSession()).data.session : null;
  if (!sb || !session) return accountStore.set({ status: "signed-out" });

  const userId = session.user.id;
  const { data } = await sb.from("profiles").select("username").eq("user_id", userId).maybeSingle();
  accountStore.set({
    status: "signed-in",
    userId,
    email: session.user.email ?? null,
    username: (data?.username as string | undefined) ?? null,
  });
}
```

```tsx
"use client";
// Where every email link lands. The link carries token_hash and type; verifyOtp in THIS
// browser turns it into a session, so the link works even when it opens in a different
// browser from the one that signed up (a PKCE code link would not).

import { useEffect, useState } from "react";
import { accountsConfigured } from "@/lib/account/config";
import { verifyEmailLink, setNewPassword } from "@/lib/account/auth";

type Phase = "checking" | "confirmed" | "new-password" | "done" | "failed";

export default function ConfirmView() {
  const [phase, setPhase] = useState<Phase>("checking");
  const [error, setError] = useState<string | null>(null);
  const [password, setPassword] = useState("");
  const [busy, setBusy] = useState(false);

  useEffect(() => {
    const q = new URLSearchParams(window.location.search);
    const tokenHash = q.get("token_hash");
    const type = q.get("type");
    if (!accountsConfigured() || !tokenHash || (type !== "email" && type !== "signup" && type !== "recovery")) {
      setPhase("failed");
      return;
    }
```

```ts
// ── The sync hook ────────────────────────────────────────────────────────────
// ONE listener, set by lib/account/syncQueue.ts while someone is signed in. It hears the
// KEY of every save to the real localStorage and nothing else; it reads the value back
// itself, later, so a store's hot path pays one function call. An injected test storage
// never reaches it. A listener that throws cannot break the save that called it.

type SaveListener = (key: string) => void;
let saveListener: SaveListener | null = null;

export function setPersistSaveListener(fn: SaveListener | null): void {
  saveListener = fn;
}

/** Raw read for the sync layer: any version, or null when missing or corrupt. */
export function loadEnvelope(key: string, storage?: StorageLike): PersistEnvelope<unknown> | null {
  const s = resolveStorage(storage);
  if (!s) return null;
  try {
    const raw = s.getItem(key);
    if (!raw) return null;
    const env = JSON.parse(raw) as PersistEnvelope<unknown> | null;
    if (!env || typeof env !== "object" || typeof env.v !== "number" || !("d" in env)) return null;
    return env;
  } catch {
    return null;
  }
}

/** Raw write for the sync layer. null removes the key. Never tells the save listener:
 *  a value that came FROM the account must not be queued to go back up. */
export function saveEnvelope(key: string, env: PersistEnvelope<unknown> | null, storage?: StorageLike): void {
  const s = resolveStorage(storage);
  if (!s) return;
  try {
    if (env === null) s.removeItem(key);
    else s.setItem(key, JSON.stringify(env));
  } catch {
    /* quota exceeded / private mode - non-fatal */
  }
}
```

```ts
/** Whole keys that hold a secret and never sync. They stay through a sign-out (the person
 *  may sign back in), but a DIFFERENT person signing in on this browser removes them, so
 *  their alerts cannot go to the last person's Telegram. */
export const DEVICE_SECRET_KEYS: readonly string[] = ["tn.telegram.v1"];

// ── Pure transforms ──────────────────────────────────────────────────────────

function isObject(v: unknown): v is Record<string, unknown> {
  return !!v && typeof v === "object" && !Array.isArray(v);
}

/** JSON with object keys sorted at every depth. Postgres jsonb reorders keys, so a plain
 *  JSON.stringify would see a change where there is none and upload it again. */
export function stableJson(value: unknown): string {
  if (Array.isArray(value)) return `[${value.map(stableJson).join(",")}]`;
  if (isObject(value)) {
    return `{${Object.keys(value).sort().map((k) => `${JSON.stringify(k)}:${stableJson(value[k])}`).join(",")}}`;
  }
  return JSON.stringify(value) ?? "null";
}

/** What leaves this device: the stored value minus its localOnly fields. */
export function toRemote(key: string, data: unknown): unknown {
  const spec = syncSpec(key);
  if (!spec?.localOnly || !isObject(data)) return data;
  const out: Record<string, unknown> = {};
  for (const [k, v] of Object.entries(data)) if (!(k in spec.localOnly)) out[k] = v;
  return out;
}

/** What this device stores: the account's value plus this device's localOnly fields. */
export function fromRemote(key: string, remote: unknown, local: unknown | null): unknown {
  const spec = syncSpec(key);
  if (!spec?.localOnly || !isObject(remote)) return remote;
  const base = toRemote(key, remote) as Record<string, unknown>;
  const loc = isObject(local) ? local : {};
  const out: Record<string, unknown> = { ...base };
  for (const [field, fallback] of Object.entries(spec.localOnly)) {
    out[field] = field in loc ? loc[field] : fallback;
  }
  if (key === "tn.map.pins.v1") {
    const ids = new Set((Array.isArray(base.pins) ? base.pins : []).map((p) => (p as { id?: unknown }).id));
    if (!ids.has(out.activeId)) out.activeId = null;
  }
  return out;
}

function itemsAt(rule: ListRule, v: unknown): { id?: unknown }[] {
  const arr = rule.at === "root" ? v : isObject(v) ? v.pins : undefined;
  return Array.isArray(arr) ? (arr.filter((x) => isObject(x)) as { id?: unknown }[]) : [];
}

/** First sign-in on a browser with data: union by id, the account's copy wins, then the
 *  store's cap. Returns the REMOTE shape (no localOnly fields). */
export function mergeList(key: string, remote: unknown, local: unknown): unknown {
  const rule = syncSpec(key)?.list;
  if (!rule) return remote;
  const acct = itemsAt(rule, remote);
  const seen = new Set(acct.map((x) => x.id));
  let merged = [...acct, ...itemsAt(rule, local).filter((x) => !seen.has(x.id))];
  if (rule.cap !== undefined && merged.length > rule.cap) {
    merged = rule.keep === "last" ? merged.slice(-rule.cap) : merged.slice(0, rule.cap);
  }
  if (rule.at === "root") return merged;
  return { ...(toRemote(key, isObject(remote) ? remote : {}) as Record<string, unknown>), pins: merged };
}
```

```ts
// THE SYNC DECISIONS, and nothing else. Pure: it reads localStorage through a function it is
// given and returns a plan. lib/account/runtime.ts carries the plan out. Rules
// (docs/superpowers/specs/2026-10-15-accounts-design.md, "Sync behaviour"):
//   - push a key when its remote shape differs from the last agreed one;
//   - pull a key when the account's copy is newer AND this device has no unsent change;
//   - an unsent local change wins (it is the newest thing this person did here);
//   - never apply a row with a different schema version; push when this device is newer;
//   - first sign-in: lists merge by id, everything else takes the account;
//   - a different person on this browser: take the account, remove the rest.

import type { PersistEnvelope } from "@/lib/shell/persist";
import { SYNC_KEY_NAMES, DEVICE_SECRET_KEYS, syncSpec, stableJson, toRemote, fromRemote, mergeList } from "@/lib/account/syncKeys";
import type { KeyMeta, SyncMeta } from "@/lib/account/syncMeta";

export interface RemoteRow { key: string; version: number; value: unknown; updated_at: string }
export type LocalRead = (key: string) => PersistEnvelope<unknown> | null;
export interface PushItem { key: string; version: number; value: unknown; json: string }
/** envelope null = remove the key from this browser; meta null = forget it in the meta. */
export interface Write { key: string; envelope: PersistEnvelope<unknown> | null; meta: KeyMeta | null }
export interface Plan { writes: Write[]; push: string[] }

const ALLOWED = new Set(SYNC_KEY_NAMES);
// Postgres sends 6 fractional digits ("...:00.123456+00:00"). ECMAScript's date format has 3,
// and a strict engine may refuse more, so trim before parsing.
const ms = (iso: string): number => Date.parse(iso.replace(/(\.\d{3})\d+/, "$1")) || 0;

function remoteJson(key: string, env: PersistEnvelope<unknown> | null): string | null {
  return env ? stableJson(toRemote(key, env.d)) : null;
}

export function planPush(keys: readonly string[], read: LocalRead, meta: SyncMeta): PushItem[] {
  const out: PushItem[] = [];
  for (const key of keys) {
    if (!ALLOWED.has(key)) continue;
    const env = read(key);
    if (!env) continue;
    const value = toRemote(key, env.d);
    const json = stableJson(value);
    if (meta.keys[key]?.json === json) continue;
    out.push({ key, version: env.v, value, json });
  }
  return out;
}

function take(key: string, row: RemoteRow, local: PersistEnvelope<unknown> | null): Write {
  const d = fromRemote(key, row.value, local?.d ?? null);
  return { key, envelope: { v: row.version, d }, meta: { json: stableJson(toRemote(key, d)), at: row.updated_at } };
}

export function planPull(rows: RemoteRow[], read: LocalRead, meta: SyncMeta): Plan {
  const plan: Plan = { writes: [], push: [] };
  for (const row of rows) {
    const { key } = row;
    if (!ALLOWED.has(key)) continue;
    const local = read(key);
    if (local && local.v !== row.version) {
      if (local.v > row.version) plan.push.push(key);
      continue;
    }
    const km = meta.keys[key];
    if (local && km && remoteJson(key, local) !== km.json) {
      plan.push.push(key);
      continue;
    }
    if (km && ms(row.updated_at) <= ms(km.at)) continue;
    plan.writes.push(take(key, row, local));
  }
  return plan;
}

export function planSignIn(rows: RemoteRow[], read: LocalRead, meta: SyncMeta, userId: string): Plan {
  const plan: Plan = { writes: [], push: [] };
  const sameBrowserOwner = meta.lastUserId === null || meta.lastUserId === userId;
  const byKey = new Map(rows.filter((r) => ALLOWED.has(r.key)).map((r) => [r.key, r]));
  for (const key of SYNC_KEY_NAMES) {
    const row = byKey.get(key);
    const local = read(key);
    if (row && local && local.v !== row.version) {
      if (local.v > row.version && sameBrowserOwner) plan.push.push(key);
      continue;
    }
    if (!row) {
      if (!local) continue;
      if (sameBrowserOwner) plan.push.push(key);
      else plan.writes.push({ key, envelope: null, meta: null });
      continue;
    }
    if (local && sameBrowserOwner && syncSpec(key)?.list) {
      const merged = mergeList(key, row.value, local.d);
      const d = fromRemote(key, merged, local.d);
      // meta records the ACCOUNT's shape, so planPush sees the merged value as a change.
      plan.writes.push({ key, envelope: { v: row.version, d }, meta: { json: stableJson(toRemote(key, row.value)), at: row.updated_at } });
      if (stableJson(merged) !== stableJson(toRemote(key, row.value))) plan.push.push(key);
      continue;
    }
    // A different person gets the fresh-device defaults for every localOnly field, never
    // the last person's webhook addresses.
    plan.writes.push(take(key, row, sameBrowserOwner ? local : null));
  }
  if (!sameBrowserOwner) {
    for (const key of DEVICE_SECRET_KEYS) if (read(key)) plan.writes.push({ key, envelope: null, meta: null });
  }
  return plan;
}
```

```ts
"use client";
// THE UPLOAD QUEUE. While someone is signed in, persist.ts tells it the key of every save.
// It waits 2 s after the last save, plans the push (only changed, allowlisted keys, secrets
// stripped), and sends ONE upsert. On failure it retries at 5 s, 30 s, 2 min, then on the
// next save. On pagehide it sends at once with keepalive-sized effort.

import { setPersistSaveListener, loadEnvelope } from "@/lib/shell/persist";
import { getSupabase } from "@/lib/account/client";
import { accountStore } from "@/lib/account/store";
import { SYNC_KEY_NAMES } from "@/lib/account/syncKeys";
import { planPush } from "@/lib/account/syncEngine";
import { loadSyncMeta, saveSyncMeta } from "@/lib/account/syncMeta";

const ALLOWED = new Set(SYNC_KEY_NAMES);
const DEBOUNCE_MS = 2_000;
const RETRY_MS = [5_000, 30_000, 120_000];

let userId: string | null = null;
const noted = new Set<string>();
let timer: ReturnType<typeof setTimeout> | null = null;
let attempt = 0;
let inflight: Promise<void> | null = null;

function schedule(delay: number) {
  if (timer) clearTimeout(timer);
  timer = setTimeout(() => void flush(), delay);
}

async function flush(): Promise<void> {
  if (inflight) return inflight;
  if (!userId || noted.size === 0) return;
  const keys = [...noted];
  inflight = (async () => {
    const meta = loadSyncMeta();
    const items = planPush(keys, (k) => loadEnvelope(k), meta);
    if (items.length === 0) { keys.forEach((k) => noted.delete(k)); return; }
    const sb = await getSupabase();
    if (!sb) return;
    accountStore.set({ sync: "syncing" });
    const { data, error } = await sb
      .from("user_state")
      .upsert(items.map((i) => ({ user_id: userId, key: i.key, version: i.version, value: i.value })), { onConflict: "user_id,key" })
      .select("key, updated_at");
    if (error) {
      // A rejected row (the version trigger, a size check) must not block the others
      // forever: after the last retry the noted keys are dropped until their next save.
      const wait = RETRY_MS[attempt];
      attempt++;
      accountStore.set({ sync: "offline" });
      if (wait !== undefined) schedule(wait);
      else { attempt = 0; keys.forEach((k) => noted.delete(k)); }
      return;
    }
    attempt = 0;
    const at = new Map((data ?? []).map((r) => [r.key as string, r.updated_at as string]));
    const next = loadSyncMeta();
    for (const i of items) next.keys[i.key] = { json: i.json, at: at.get(i.key) ?? new Date().toISOString() };
    saveSyncMeta(next);
    keys.forEach((k) => noted.delete(k));
    accountStore.set({ sync: "synced", lastSyncedAt: Date.now() });
  })().finally(() => { inflight = null; });
  return inflight;
}

function onPageHide() { if (noted.size) void flush(); }

export const syncQueue = {
  start(id: string) {
    userId = id;
    setPersistSaveListener((key) => { if (ALLOWED.has(key)) { noted.add(key); schedule(DEBOUNCE_MS); } });
    window.addEventListener("pagehide", onPageHide);
  },
  note(key: string) {
    if (ALLOWED.has(key)) { noted.add(key); schedule(DEBOUNCE_MS); }
  },
  flushNow(): Promise<void> {
    if (timer) clearTimeout(timer);
    return flush();
  },
  async stop(): Promise<void> {
    await this.flushNow();
    setPersistSaveListener(null);
    window.removeEventListener("pagehide", onPageHide);
    userId = null;
    noted.clear();
  },
};
```

```ts
"use client";
// THE ACCOUNT'S BOOT STEP. ConsoleShell calls startAccount() once, AFTER its hydrate effect,
// so every store already holds this browser's values. Then:
//   1. find the session (a localStorage read first; no library for signed-out visitors);
//   2. fetch the account's rows;
//   3. a new person on this browser -> planSignIn, apply, push, reload;
//      the same person -> planPull; if anything is newer, apply and reload ONCE, but only
//      within 4 s of boot - later, ask first (a reload under someone's hands loses work);
//   4. start the upload queue; record today in activity_days (M4).
// A reload is the only safe way to apply pulled values: the hydrate order in ConsoleShell
// is load-bearing (variant before inspector, rules after inspector).

import { accountsConfigured, hasStoredSession } from "@/lib/account/config";
import { getSupabase } from "@/lib/account/client";
import { accountStore } from "@/lib/account/store";
import { loadEnvelope, saveEnvelope } from "@/lib/shell/persist";
import { planPull, planSignIn, type Plan, type RemoteRow } from "@/lib/account/syncEngine";
import { loadSyncMeta, saveSyncMeta, type SyncMeta } from "@/lib/account/syncMeta";
import { syncQueue } from "@/lib/account/syncQueue";

const AUTO_RELOAD_WINDOW_MS = 4_000;
const RELOAD_FLAG = "tn.account.reloaded";
let started = false;
let pending: { plan: Plan; meta: SyncMeta } | null = null;

function apply(plan: Plan, meta: SyncMeta): SyncMeta {
  const next: SyncMeta = { ...meta, keys: { ...meta.keys } };
  for (const w of plan.writes) {
    saveEnvelope(w.key, w.envelope);
    if (w.meta) next.keys[w.key] = w.meta;
    else delete next.keys[w.key];
  }
  return next;
}

function reloadOnce(): boolean {
  try {
    if (sessionStorage.getItem(RELOAD_FLAG)) return false;
    sessionStorage.setItem(RELOAD_FLAG, "1");
  } catch {
    return false;
  }
  window.location.reload();
  return true;
}

/** The Account tab's "Load them" button. */
export function applyPendingAndReload(): void {
  if (!pending) return;
  saveSyncMeta(apply(pending.plan, pending.meta));
  pending = null;
  window.location.reload();
}

export async function startAccount(): Promise<void> {
  if (started) return;
  started = true;
  const bootAt = performance.now();
  if (!accountsConfigured()) return accountStore.set({ status: "off" });
  if (!hasStoredSession()) return accountStore.set({ status: "signed-out" });

  accountStore.set({ status: "loading" });
  const sb = await getSupabase();
  const session = sb ? (await sb.auth.getSession()).data.session : null;
  if (!sb || !session) return accountStore.set({ status: "signed-out" });

  const userId = session.user.id;
  let meta = loadSyncMeta();
  accountStore.set({ status: "signed-in", userId, email: session.user.email ?? null, username: meta.username });

  const [rowsRes, profRes] = await Promise.all([
    sb.from("user_state").select("key, version, value, updated_at"),
    sb.from("profiles").select("username").eq("user_id", userId).maybeSingle(),
  ]);
  const username = (profRes.data?.username as string | undefined) ?? meta.username;
  accountStore.set({ username });
  meta = { ...meta, username };

  if (rowsRes.error) {
    accountStore.set({ sync: "offline" });
    syncQueue.start(userId);
    return;
  }
  const rows = (rowsRes.data ?? []) as RemoteRow[];
  const read = (k: string) => loadEnvelope(k);

  if (meta.userId !== userId) {
    // A new sign-in on this browser (password, or an email link).
    const plan = planSignIn(rows, read, meta, userId);
    const next = apply(plan, { ...meta, userId, lastUserId: userId });
    saveSyncMeta(next);
    syncQueue.start(userId);
    plan.push.forEach((k) => syncQueue.note(k));
    await syncQueue.flushNow();
    // reloadOnce, not reload: if storage is broken the meta never saves, and a plain
    // reload would loop forever.
    if (!reloadOnce()) accountStore.set({ sync: "synced", lastSyncedAt: Date.now() });
    return;
  }

  const plan = planPull(rows, read, meta);
  saveSyncMeta(meta);
  syncQueue.start(userId);
  plan.push.forEach((k) => syncQueue.note(k));

  if (plan.writes.length === 0) {
    try { sessionStorage.removeItem(RELOAD_FLAG); } catch { /* private mode */ }
    accountStore.set({ sync: "synced", lastSyncedAt: Date.now() });
    return;
  }
  if (performance.now() - bootAt < AUTO_RELOAD_WINDOW_MS) {
    saveSyncMeta(apply(plan, meta));
    if (reloadOnce()) return;
  }
  pending = { plan, meta };
  accountStore.set({ notice: "Your account has newer settings from another device." });
}
```

```ts
// DELETE MY ACCOUNT, as a pure function of three request values and an admin port, so
// every answer is unit-tested. The route reads the headers (so the /privacy guard sees
// which route reads an identifying header) and wires the real Supabase admin client in.
//
// No upstream text is ever returned (the credential-oracle rule from /api/feedback): a
// caller learns only 204, 401, 403, 502 or 503.

export interface DeleteAdmin {
  /** The user id this access token belongs to, verified against Supabase, or null. */
  userIdForToken(token: string): Promise<string | null>;
  deleteUser(id: string): Promise<boolean>;
}

export interface DeleteInput {
  url: string;
  origin: string | null;
  authorization: string | null;
}

const json = (status: number, error: string) =>
  Response.json({ ok: false, error }, { status, headers: { "Cache-Control": "no-store" } });

function sameOrigin(input: DeleteInput): boolean {
  if (!input.origin) return false;
  try {
    return new URL(input.origin).host === new URL(input.url).host;
  } catch {
    return false;
  }
}

export async function handleAccountDelete(input: DeleteInput, admin: DeleteAdmin | null): Promise<Response> {
  if (!admin) return json(503, "Account deletion is not available here.");
  if (!sameOrigin(input)) return json(403, "Not allowed.");
  const auth = input.authorization ?? "";
  const token = auth.startsWith("Bearer ") ? auth.slice(7).trim() : "";
  if (!token) return json(401, "Sign in again.");
  try {
    const id = await admin.userIdForToken(token);
    if (!id) return json(401, "Sign in again.");
    if (!(await admin.deleteUser(id))) return json(502, "Could not delete the account just now.");
    return new Response(null, { status: 204, headers: { "Cache-Control": "no-store" } });
  } catch {
    return json(502, "Could not delete the account just now.");
  }
}
```

```ts
// lib/account/serverAuth.ts
// THE ONE SERVER-SIDE ACCOUNT CHECK, and the ONLY file that reads the Supabase secret key
// (tests/unit/account-secret-scope.test.ts pins that). Every route that needs a signed-in
// person calls requireUser(); none reads the key itself. Sam chose this on 2026-10-15 so
// later gated routes (a Pro tier, breach-awareness Tier C) share one check.
//
// requireUser() makes a network call to Supabase (auth.getUser), so it also refuses a token
// whose user was deleted after the token was issued. It gates on identity only. A plan or a
// "vetted" flag belongs in a server-written entitlements table, never in user_metadata,
// which the user can edit. That table is not built yet.
import { createClient, type SupabaseClient } from "@supabase/supabase-js";

export interface ServerUser {
  id: string;
  email: string | null;
}

/** PURE: the token from "Bearer <token>", or null. Case-sensitive, as RFC 6750 writes it. */
export function bearerToken(authorization: string | null): string | null {
  if (!authorization?.startsWith("Bearer ")) return null;
  const token = authorization.slice(7).trim();
  return token || null;
}

let admin: SupabaseClient | null | undefined;

/** The admin client, or null when the server has no secret key (accounts dormant here). */
export function supabaseAdmin(): SupabaseClient | null {
  if (admin !== undefined) return admin;
  const url = process.env.NEXT_PUBLIC_SUPABASE_URL?.trim();
  const secret = process.env.SUPABASE_SECRET_KEY?.trim();
  admin = url && secret ? createClient(url, secret, { auth: { persistSession: false, autoRefreshToken: false } }) : null;
  return admin;
}

/** Who sent this request, verified with Supabase, or null. Never throws. */
export async function requireUser(authorization: string | null): Promise<ServerUser | null> {
  const sb = supabaseAdmin();
  const token = bearerToken(authorization);
  if (!sb || !token) return null;
  try {
    const { data, error } = await sb.auth.getUser(token);
    return error || !data.user ? null : { id: data.user.id, email: data.user.email ?? null };
  } catch {
    return null;
  }
}
```

```ts
// tests/e2e/accounts.spec.ts
// Two browser contexts, one account: a board change in A reaches B. Needs .env.local with
// the DEV project's three values. Run: npx playwright test tests/e2e/accounts.spec.ts
import { test, expect } from "@playwright/test";
import { createClient } from "@supabase/supabase-js";
import { randomBytes } from "node:crypto";

const url = process.env.NEXT_PUBLIC_SUPABASE_URL!;
const secret = process.env.SUPABASE_SECRET_KEY!;
test.skip(!url || !secret, "needs the dev Supabase project in the environment");

test("settings follow the account to a second browser", async ({ browser }) => {
  const admin = createClient(url, secret, { auth: { persistSession: false } });
  const tag = randomBytes(4).toString("hex");
  const email = `e2e-${tag}@example.com`;
  const password = `e2e-${randomBytes(10).toString("hex")}`;
  const { data, error } = await admin.auth.admin.createUser({
    email, password, email_confirm: true, user_metadata: { username: `e2e_${tag}` },
  });
  expect(error).toBeNull();
  try {
    const signIn = async () => {
      const ctx = await browser.newContext();
      const page = await ctx.newPage();
      await page.goto("/app");
      await page.getByRole("button", { name: "Sign in" }).first().click();
      await page.getByLabel("Email").fill(email);
      await page.getByLabel("Password").fill(password);
      await page.locator(".tn-account-btn.is-primary").click();
      await expect(page.locator(".tn-account-trigger")).toContainText(`e2e_${tag}`, { timeout: 15_000 });
      return page;
    };
    const a = await signIn();
    // A real store change through the UI, so savePersisted tells the queue.
    await a.getByRole("button", { name: "Settings" }).click();
    await a.getByRole("tab", { name: "Display" }).click();
    await a.getByRole("group", { name: "Interface language" }).getByRole("button", { name: "ES" }).click();
    await a.waitForTimeout(3_500); // the queue's 2 s debounce, plus the upsert

    const b = await signIn();
    await expect.poll(async () => b.evaluate(() => localStorage.getItem("tn.lang.v1"))).toContain('"es"');
  } finally {
    await admin.auth.admin.deleteUser(data!.user!.id);
  }
});
```
